# Подготовка документации криптотурнира

Цель: регистрация пользователя, проверка допуска к турниру и показ результатов в лидерборде. Готовый pnl загружает администратор; порядок leaderboard — pnl DESC. ROI необязателен и справочен. Кошелёк подаётся с хэшем вывода, проверяется вручную и блокируется от смены после TOURNAMENT_START_AT.

## Этапы подготовки

| Этап | Результат |
| --- | --- |
| 1. Увязать исходные правила | Одинаковые условия регистрации, допуска и показа во всех документах |
| 2. Описать сценарии | Действия, запросы, проверки, записи, ответы, ошибки и повторные действия |
| 3. Зафиксировать маппинг | Источник → ключ API → поле БД → потребитель |
| 4. Описать алгоритмы | Условия, порядок операций, транзакции и вычисляемые значения |
| 5. Зафиксировать БД и API | Шесть таблиц и полные формы обмена данными |
| 6. Описать интерфейсы и приёмку | Состояния экранов и проверяемые результаты задач |
| 7. Увязать уточнения | Решения владельца включены в контракт версии 0.2 |

Подробные материалы находятся в [комплекте документации](README.md). В существующие таблицы добавлены только необходимые pnl и withdrawal_tx_hash; новых таблиц нет. Автоматический скоринг, новые сущности турниров, аудит, версии записей и протокол подписания кошелька не включаются.
