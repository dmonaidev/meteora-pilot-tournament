# Уточнение1.3 — название турнира из админки

Поручение владельца08.10.2026: рядом с настройками расписания добавить изменение названия, текущее **PILOT TOURNAMENT**. Поправка времени из1.1 действует:24часа и явная пометка UTC.

## Данные и API

Миграция010 добавляет `tournament_settings.tournament_name TEXT NOT NULL DEFAULT 'PILOT TOURNAMENT'`. Имя — plain text1–80символов после trim, без управляющих символов C0/C1; HTML не исполняется. Пустое имя не принимается. Число таблиц прежнее, профили/даты/ссылка партнёра не меняются.

- `GET /api/v1/public/tournament/name` → `{tournament_name: string}`, доступ гостю.
- `GET /api/v1/admin/tournament/name` → тот же объект, только admin.
- `POST /api/v1/admin/tournament/name` принимает строго `{tournament_name: string}`, возвращает сохранённый объект. Неверный ввод —422 VALIDATION_ERROR, права —401/403. Обновляется только имя; изменение разрешено независимо от старта/окончания турнира. Никаких внешних запросов.

Существующие API расписания/партнёра сохраняют свои схемы. Имя не используется в роли пользователя, идентификаторах турнира, токенах, сортировке или ссылках.

## Интерфейс

В **Админка → Настройки турнира** отдельная форма «Название турнира», одноимённое поле и кнопка «Сохранить название». Начальное значение PILOT TOURNAMENT берётся из сервера, повторное чтение/обновление страницы его сохраняет. Уход с раздела отменяет чтение; запоздавшее завершение не возвращает прежний экран.

Серверное значение заменяет прежнюю строку PILOT TOURNAMENT в бренде гостевой страницы/меню/ЛК и заголовке лидерборда. METEORA $MET, Liquidity Providers и by Meteora Plus Community сохраняются. Generic названия «Турнир», «Лидерборд», «Личный кабинет» не переименовываются. После сохранения видимые блоки обновляются без нового входа; гостю достаточно загрузить страницу заново. При чтении не подменять сохранённое имя пустой строкой; ошибку явно обрабатывать.

## Проверки

Отдельная БД: default, права доступа, trim/пустой/control/лишние ключи, сохранение/повторное чтение/очистка невозможна, даты и ссылка неизменны. Браузер: изменение через админку, немедленное отображение в меню, гостевой странице и лидерборде; обновление сохраняет имя; длинное имя не создаёт переполнения390px. Живые профили и расписание не менять. Деплой не выполнять.
