# Единственная демонстрационная запись

По поручению владельца удалить восемь старых демонстрационных пользователей (Telegram ID 100001–100006, 900001, 900002) и их зависимые кошельки, UID, scoring и сессии. Оставить реальные accounts 940001 (AdministratorProfile) и 940002 (ExternalProfile). Исходный импортированный реестр допуска — реальные данные, удаляется только его прежняя строка 100001 с группой «Демо».

Добавить одного демонстрационного пользователя с зарезервированным синтетическим Telegram ID 800000000000026, username без ведущего @ `TestUserDEMO_261009_16:54` и точным display_name `TestUserDEMO_261009_16:54`. Username содержит двоеточие и является демонстрационной меткой, а не существующим Telegram-аккаунтом; автоматические сообщения на этот синтетический ID не отправляются. Демо не даёт обхода входа через Telegram.

Display name из поручения содержит 25 символов. Для ручных записей базы допускается 3–100 символов, соответствуя существующему VARCHAR(100); ограничение пользовательской регистрации в API 3–20 сохраняется. Миграция 005 меняет только ограничение users.display_name. API выдаёт строку без усечения.

Регистрация APPROVED_MANUAL с заметкой «Демонстрационная запись владельца; Telegram не существует; данные тестовые». Кошелёк — сгенерированный корректный адрес Solana (32 байта Base58), validation_status VALID. Заданный шаблон PablAddr…Test01 не может быть адресом Solana из-за запрещённых символов l/0. UID `000000000` хранится строкой, reward_type PARTNER_GIFTS, uid_status VALID. withdrawal_tx_hash — обозначенная демонстрационная строка, ручная проверка VALID как запрошено.

В таблице результатов демонстрационные значения: initial_capital 1000, current_capital 1250, pnl 250, in_positions_amount 0, ROI 25. Все помечены тестовыми в admin_notes. В реестре допуска для этого ID группа «Демо», system_notes содержит ту же демонстрационную метку. Лидерборд показывает точное имя и SpecialPartnerGift. Настройка даты турнира и профили двух реальных пользователей не меняются.
