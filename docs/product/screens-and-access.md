# Экраны платформы и права доступа

Версия 1.3. Существующий интерфейс переносится из `web/src/`. Подробные поля и API — в [спецификации доступа и кабинета](access-and-cabinet.md), границы исправлений — в [правилах фронтенда](../delivery/design-preservation.md). Текущее поручение: сначала развернуть готовое решение, затем исправить отображение и вёрстку. **Изменения сценариев, алгоритмов, API, структуры БД и данных — только после отдельного явного разрешения пользователя, владельца проекта.**

## Публичная главная

Бренд, кнопка регистрации на турнир, правила и ссылка лидерборда. Даты UTC показываются по стадии: до закрытия регистрации — регистрация до, начало и конец турнира; затем начало и конец; после старта — турнир до; после окончания — завершён. Неназначенные даты обозначены явно.

Четыре карточки: участники в турнире, капитал в турнире, общий PNL и оборот LP в SOL. Значения приходят с API: отсутствие — «—», настоящий ноль остаётся нулём. Демобаннер Special Gift: техника Apple на XXX $, раскрытие суперприза за три дня до конца и ссылка квалификации из админки. Сохранить отметку ДЕМО и текущую раскладку. Лишнюю кнопку «В лидерборд» в показателях не возвращать.

## Вход и регистрация

Вход: Telegram username с @ или без него либо числовой ID; существующий бот отправляет шестизначный код. Окно показывает адрес бота, кнопку открытия, /start, поле кода и ограничения. Переписывание длинной ссылки на телефоне не требуется. Код живёт пять минут, повторная выдача — через 90 секунд; сохранены ожидание, ошибка и истечение.

Регистрация открывает существующее окно с именем в турнире, Telegram username/ID, ссылкой правил и изначально пустой обязательной галочкой согласия с текущей редакцией. Без опубликованных правил или вне окна регистрации новый вход в турнир закрыт. После подтверждения администратору открывается админка, участнику — кабинет. Действующая сессия восстанавливается без нового кода.

## Правила турнира

Окно доступно с главной, регистрации и лидерборда. Показываются текущая редакция, её дата и текст; сохранённый архив доступен для просмотра. Согласие привязано к UUID и серверному времени. Новая публикация не теряет заполненную форму регистрации.

## Личный кабинет

Приветствие, имя и краткий сохранённый статус Special Gift/Respect Gift и квалификации. Отдельный блок допуска сообщает подтверждение, ожидание или отклонение; внешнему участнику видны отсутствие допуска и контакты администраторов.

Слева форма: имя и подтверждённый Telegram readOnly, кошелёк Solana, предложение Special Gift с рефссылкой и галочка UID. Справа ручные статусы и дорожная карта. На мобильном — существующая вертикальная раскладка.

| Состояние | Отображение |
| --- | --- |
| Первый незаполненный профиль | UID включён по умолчанию |
| UID включён | UID и хэш вывода обязательны, ведущие нули UID сохраняются |
| UID выключен | Условные поля скрыты, предупреждение об отказе от специальных призов; основное участие доступно |
| Ввод кошелька/UID | Через 500мс фоновая проверка; статус под полем: проверяем, нет дубликатов, дубликат или ошибка |
| Неверный формат/чужой дубликат | Поле отмечено, сохранение блокируется; собственные значения разрешены |
| UNDER_REVIEW | Ожидание ручной проверки |
| INVALID | Причина и исправление доступных данных |
| Старт наступил, кошелёк существует | Адрес readOnly, сообщение о закреплении на турнир |
| Кошелёк VALID | Блок загруженных результатов или сообщение, что данные ещё не загружены |
| PENDING_VALIDATION/REJECTED | Явное сообщение и ссылки @LeoCryptus / @D_mOnII |

Проверка дубликатов не означает ручной VALID. Категория назначается сервером; пользователь её не выбирает. Итоговый статус показывает сохранённые данные, а не несохранённую галочку. PNL, ROI и капитал пользователь не редактирует.

## Special Gift и дорожная карта

Над UID — предложение и рефссылка из админки. Минипанель «Как участвовать в Special Gift?» не сбрасывает форму. Шаги: регистрация турнира; свежая регистрация биржи по рефссылке; депозит от 100 USDT; обмен USDT на SOL на споте, можно лимитным ордером; вывод SOL на Ваш турнирный кошелёк; UID и хэш; кошелёк для турнира.

Биржевые шаги относятся к Special Gift. Администратор вручную проверяет регистрацию, депозит, объём спот-обмена, UID и хэш. Не добавлять имитацию автоматической проверки биржи. Текущий шаг и ожидание отмечены существующими кружками и статусами.

## Лидерборд

Бренд, расписание, четыре публичные метрики и таблица опубликованных результатов. Строки: место, имя, сокращённый кошелёк, reward_tag, начальный/текущий капитал, абсолютный PNL и справочный ROI при наличии. Порядок приходит с сервера: PNL по убыванию. UID, хэш, Telegram ID и административные заметки не публикуются.

Сохранить обновление, пустые/ошибочные состояния и навигацию с действующей сессией. Кнопку перехода «В лидерборд» внутри самого лидерборда не добавлять.

## Продление сессии

Сессия 30 минут; за последние пять минут на приватных экранах появляется баннер, отсчёт и «Продолжить через Telegram». Бот присылает кнопку владельцу. Нажатие сайта само срок не продлевает. Подтверждение даёт ещё 30 минут без нового кода; без подтверждения после истечения нужен новый вход.

## Админка

Плитки сразу переключают нижнюю область; поздние ответы не возвращают прошлый раздел. Таблицы имеют поиск, размер страницы, пагинацию и обновление. Username ищется с @ и без него.

| Раздел | Содержимое |
| --- | --- |
| Участники | Имя, username, числовой Telegram ID, раскрываемые карточки; допуск с комментарием, проверки кошелька/UID по текущим значениям |
| Реестр допуска | Строки и импорт CSV/JSON с шаблоном |
| Кошельки | Адреса, хэши, статусы и причины отказов |
| UID и награды | UID, тип участия, ручная квалификация партнёра |
| Результаты | PNL, капитал, позиции, ROI, оборот LP; атомарный импорт CSV/JSON |
| Сессии входа | Диагностика без кодов, токенов и секретных ссылок |
| Настройки турнира | Отдельные формы названия, четырёх дат UTC и рефссылки; календарь, время 24 часа и собственный выбор часов |
| Правила | Редактор, TXT/MD, черновик, публикация, архив, копирование и явное удаление архивного текста |

Публикация правил архивирует прежнюю редакцию. Действующая/архивная редакция неизменяема; редактируется черновик. Удаление требует подтверждения и сохраняет метаданные согласий. Название и ссылка обновляются после сохранения, прошедшие даты штатно не меняются.

## Права

Гостю доступны главная, метрики, лидерборд, публичные правила и допустимая регистрация/вход. Участник видит только свой кабинет. Администратор дополнительно видит все восемь разделов, модерацию, импорт и настройки. Подтверждение ботом — сервисный API. Роль проверяется backend по подтверждённому Telegram ID; скрытая кнопка не заменяет проверку прав.
