# Проверка локального доступа 0.7

08.10.2026. Обновлён серверный срок до 1800 секунд, внедрены постоянные серверные сессии, подтверждение через callback Telegram, автоматическая очистка кнопок и общий лимит выдачи кода 90 секунд.

- Сборка Vite успешна.
- Полный изолированный серверный прогон: 54 теста пройдено, 0 ошибок и пропусков. После него добавлена проверка harmless Telegram `message is not modified`; все 7 тестов соответствующего bot/session модуля прошли, включая новую проверку. Текущий общий набор содержит 55 тестов.
- Пять браузерных сценариев проверены: четыре прошли в общем прогоне, сценарий продления/истечения после исправления моделирования времени успешно перепроверен отдельно. Реальная БД в изменяющих тестах не использовалась.
- Реальная локальная БД: удалены 8 прежних демонстрационных пользователей и их зависимые данные, осталось ровно 3 users: AdministratorProfile, ExternalProfile, TestUserDEMO_261009_16:54. Импортированный реестр реальных допусков сохранён; прежняя запись «Демо» заменена новой.
- Новая демозапись имеет точное display_name/username, UID `000000000` VALID, кошелёк VALID, PARTNER_GIFTS; показана в гостевом лидерборде как SpecialPartnerGift с демонстрационным PNL 250.
- Реальная локальная админка: подтверждены 3 карточки, поиск по полному @демо-имени, показ UID/кошелька/статусов; экран 390 px без горизонтального переполнения, page errors отсутствуют. Проверка не меняла профили/решения. Временная проверочная серверная сессия удалена.
- Действующие локальные настройки: AUTH_JWT_TTL_SECONDS=1800, LOCAL_DEMO=false. `/health` 200, журналы app/bot ошибок пусты. Серверный деплой не выполнялся.
- Ранее подтверждена реальная отправка OTP в Telegram; новый callback продления, снятие клавиатуры и границы срока проверены через тестовый транспорт. Ручной проход новой кнопки с реальным телефоном остаётся частью финальной приёмки.
