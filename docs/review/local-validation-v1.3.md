# Локальная проверка1.3 — название и время24часа

Дата08.10.2026. Основание: [название турнира1.3](../decisions/tournament-name-v1.3.md) и поправка формата ввода в [UTC1.1](../decisions/utc-admin-v1.1.md).

## Изменения

В настройках добавлена отдельная форма названия турнира с текущим PILOT TOURNAMENT. Сервер хранит имя в существующей tournament_settings; миграция010 добавляет одну колонку. Новый public/name и защищённый admin/name дают единый источник бренду и лидерборду. Сохранение меняет только имя.

Англоязычный native time input отображал AM/PM. Время заменено на детерминированный текстовый24часовой ввод ЧЧ:ММ, с примечанием «24 часа · UTC» и панелью часов00–23/минут00–59. Сохранённые ненулевые секунды видны, неизменённые ISO сохраняют точность. Календарь остаётся нативным, форматирование публичных дат использует UTC/hourCycle:h23. Закрытие выбора через Escape/Отмена не сохраняет расписание.

## Проверки

Сборка frontend прошла. **82 серверных теста, 11 браузерных сценариев прошли**, без пропусков серверных проверок. До добавления названия отдельно прошли два целевых сценария сохранения UTC и выбора времени; затем полный браузерный прогон повторён с названием. Браузер использует en-US и America/Los_Angeles.

Новые проверки названия: default, права, строгая схема, trim/пустое/контрольные символы/длина, запись после старта без изменения дат/ссылки/профилей, повторная миграция и чтение. В браузере: сохранение из админки немедленно обновляет бренд; refresh, гостевая страница и лидерборд видят то же имя;80символов без пробелов не создают горизонтального переполнения390px.

Проверки времени: часы21 и минуты35 дают21:35 без AM/PM;25:00 и09:00 PM невалидны. Ввод12:00 сохраняет12:00Z и восстанавливается как12:00. Неполная пара не пишет настройки. Панель выбора использует часы00–23, текущий UTC явно подписан, hint связан с input через уникальный aria-describedby. Прежние сценарии регистрации/правил/дубликатов/сессий/PNL/партнёрской квалификации прошли.

## Рабочий localhost

API локально перезапущен для миграции010 и новых маршрутов. Бот и PostgreSQL не перезапускались. На свежей сборке прочитаны существующие даты и рефссылка, проверены форма имени и бренд, четыре24часовых поля, подсказки UTC и мобильный выбор времени. Ненулевые секунды59 существующих дат отображаются явно. По Escape панель закрывается. Осмотрен редактор1440px и панель390px; ошибок JS/горизонтального переполнения нет.

Снимки users, wallets, partner_rewards, tournament_scoring, tournament_settings и tournament_rules до/после локальной проверки совпали. Рабочее название, даты, ссылка и профили не сохранялись, уведомления/коды не отправлялись. Временная сессия проверки удалена. Деплой не выполнялся.
