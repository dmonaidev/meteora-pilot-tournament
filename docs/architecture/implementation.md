# Реализация локального продукта

Один Node.js сервер обслуживает API и собранный React интерфейс. Telegram-бот — управляемый процесс того же проекта, обращается к общему API. Постоянные данные находятся в PostgreSQL 17; шесть таблиц соответствуют контракту 0.2.1.

Стек: Node.js 24, Fastify 5, pg, Zod, jose; React 19, Vite 7. Локально PostgreSQL запускается из embedded-postgres без Docker; это обычный сервер PostgreSQL с отдельным каталогом данных. На Ubuntu подключается PostgreSQL из существующей инфраструктуры либо Compose. Миграции и запросы совпадают.

Пользователь утвердил русский интерфейс и тёмное оформление. Бренд в локальном прототипе Synergy Tournament можно заменить при согласовании интерфейса.

Для просмотра до получения Telegram token предусмотрен отдельный локальный демонстрационный режим: реальные тестовые записи PostgreSQL и переключение синтетических аккаунтов. Он доступен только при LOCAL_DEMO=true, NODE_ENV не production и HOST=127.0.0.1. Производственный запуск с LOCAL_DEMO=true запрещён. В production маршруты /api/local-demo/* отсутствуют. Этот режим не является новым способом входа участников турнира.

Дата турнира остаётся обязательной настройкой UTC по действующему контракту. Локальный просмотр использует явно демонстрационную дату; production требует фактическое значение. Настройка даты через административный интерфейс пока не утверждена.
